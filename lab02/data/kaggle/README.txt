Titanic — классификация

train.csv: 891 реальных строк исходного набора с ответами.
test.csv: 1000 объектов без ответов.
sample_submission.csv: шаблон посылки, ровно две колонки Id,Survived.

Целевая переменная: Survived. Метрика: F1(binary, positive=1).
Отправляйте метки 0 или 1; положительный класс — 1.
Id нужен только для сопоставления строк, использовать его как признак не следует.
Подбирайте модель и параметры на собственной валидации из train.csv.
Все преобразования обучайте на обучающей части.
CSV: UTF-8, разделитель запятая, десятичный разделитель точка.
Пропуски обозначены пустыми полями.

Файлы с ответами и материалы организатора в комплект участников не входят.
Происхождение обучающих данных и лицензия описаны в SOURCES.txt.
